---
name: Edit Markdown sources, not LaTeX
description: Always edit the Markdown section files in sections/, never the LaTeX files in tex/sections/ — LaTeX is derived output built by pandoc.
type: feedback
---

Edit the Obsidian Markdown files in `sections/*.md`, not the LaTeX files in `tex/sections/*.tex`. The LaTeX is a derived output generated by pandoc via `build.sh`. Changes to `.tex` files will be overwritten on the next build.

**Why:** The Markdown files are the authoritative source. The build pipeline (pandoc + Lua filters) generates LaTeX from them. Editing `.tex` directly creates drift between source and output.

**How to apply:** For any content change, edit `sections/*.md` and then rebuild. Only edit `tex/` files for preamble/template changes that have no Markdown equivalent.
