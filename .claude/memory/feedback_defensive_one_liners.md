Adding 1-2 sentence defensive additions at the end of existing paragraphs, each mapped to a specific reviewer archetype attack, is a validated approach for strengthening evaluation prose.

**Why:** Martin confirmed multiple edits of this kind: "Great, great addition. Congratulations. Need more like this" (anti-pattern extensibility), "Another banger!" (baseline definitional advantage), "These align exactly with what Oszkár said" (systematicity argument). The pattern works because each sentence is self-contained, addresses a specific attack, and doesn't disrupt existing flow.

**How to apply:** When reviewing or strengthening a section, identify reviewer attack surfaces (using the four archetypes from VENUE.md), then propose targeted 1-2 sentence additions at natural paragraph boundaries. Each addition should name the attack it pre-empts.
