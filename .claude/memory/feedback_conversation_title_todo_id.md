name: "Conversation title starts with todo ID"
description: "When working on a todo, first message must begin with the todo ID for conversation history readability"
type: feedback
---

When working on a todo, the first message of the conversation must begin with the todo's ID (e.g., "M00 — Processing advisor notes..."). This makes conversations identifiable in Claude Code's history sidebar.

**Why:** Martin manages multiple parallel conversations and needs to find them by todo ID at a glance.

**How to apply:** Whenever a conversation is scoped to a specific todo, lead the first response with the ID and a short description.
