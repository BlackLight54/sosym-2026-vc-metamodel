---
name: "Show surrounding text in plan edits"
description: "When proposing edits in plan mode, include before/after paragraphs so Martin can judge flow in context"
type: feedback
---

When proposing text edits in a plan, always show the surrounding paragraph text (before and after the insertion point) so Martin can judge how the new sentences flow with existing prose.

**Why:** Martin said "The sentence is a button, but I am missing the larger context. Please add surrounding text to the edits." Isolated sentences can't be evaluated without seeing how they connect to what comes before and after.

**How to apply:** For each proposed edit, show exact old→new strings (the literal text being replaced and its replacement), with ~2-3 surrounding sentences for context. Bold the new additions so they stand out. Descriptive prose about what to change ("add something like...") is insufficient — Martin needs to see the precise text to approve it. When proposing multiple competing candidates for the same text, use a comparison table showing how they differ on specific dimensions (structure, tone, length, key choices) so Martin can evaluate them side by side in a single view.
