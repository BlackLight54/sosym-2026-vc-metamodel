# Cut Text Archive

Removed text preserved with recovery context, so nothing is permanently lost.

- **Naming:** `YYYY-MM-DD_description.md` (e.g., `2026-03-20_old_intro_p3.md`).
- **Each file contains:** The removed text, where it was (section and paragraph), why it was cut, and conditions under which it could be reintroduced.
- Text is archived here whenever significant prose is removed from section files during revision or restructuring.
- Do not put superseded decisions or completed todos here; those have their own archive directories.
