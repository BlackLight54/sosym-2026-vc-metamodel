# Archive — Cut Recovery

Everything removed from the paper lives here for potential reintroduction (e.g., journal extension).

## Removed text

Named `YYYY-MM-DD_description.md`. Each file contains:
- The removed text
- Where it was (section, approximate location)
- Why it was cut
- Conditions for reintroduction

## Collected references

`references/` subfolder. Structured notes from `skills/prior_work_import`.

## What does not go here

- Current state of any section (section files are authoritative)
- Cross-cutting decisions (use `context/DECISIONS.md`)
- Minor edits not worth recovering
