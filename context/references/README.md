# Reference Notes

Collected reference notes and PDFs for papers relevant to the project.

- **Structured notes:** Key references get a `.md` file summarizing claims, methods, and relevance to our binding claims. Produced by `skills/research_prior_work_import`.
- **PDFs:** Stored here where permitted, named to match the note file or BibTeX key.
- Citations are managed in Zotero and exported to `.bib`. Notes here supplement the bibliography with structured analysis.
- Do not put general research findings here; those belong in `context/archive/research/`.
