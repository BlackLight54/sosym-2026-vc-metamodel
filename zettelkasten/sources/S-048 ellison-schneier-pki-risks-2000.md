## Target use
RQ0 (anticipation precedent). This is the strongest evidence that PKI design errors CAN be anticipated before mass deployment: several of the ten risks later materialized as documented incidents. It directly supports the anticipation hypothesis that grounds the paper's forward-looking design-error argument for VC ecosystems. Must-cite item (axis d).
